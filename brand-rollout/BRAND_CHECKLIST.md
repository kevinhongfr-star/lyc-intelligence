# LYC Brand Checklist

> Use this before publishing any asset. Quick-reference version of the constitution.

---

## BEFORE YOU PUBLISH — RUN THROUGH THIS

### 1. Positioning Check
- [ ] Does the asset say "leadership intelligence firm" (not search firm, not consulting, not SaaS)?
- [ ] Is the flywheel visible — three layers, one system?
- [ ] Are we clear about what we're NOT?

### 2. Taxonomy Rule Check — THE NON-NEGOTIABLE
- [ ] Headlines and hero sections: outcome language only? No framework names?
- [ ] Framework names only appear:
  - [ ] In "powered by [X]" attribution (Level 2)
  - [ ] In depth/methodology sections (Level 3)
  - [ ] In internal documents
- [ ] Assessment names: functional name first, framework second?

### 3. Messaging Check
- [ ] Hero message variant present: "intelligence for better leadership decisions"
- [ ] Three content pillars visible where relevant?
- [ ] Maturity stack framing present where relevant?

### 4. NEXUS Check
- [ ] NEXUS is positioned as "by LYC" (endorsed, not sub-branded)?
- [ ] NEXUS never overshadows LYC in LYC-branded assets?
- [ ] Graduation path from NEXUS → programmes → search is visible (ambiently)?

### 5. Visual / Design Check
- [ ] ECHO v6 color system correct (ink, fuchsia, off, white, grays)?
- [ ] Fonts correct (Crimson Pro / DM Sans / IBM Plex Mono)?
- [ ] No decorative lines, border-radius: 6px?
- [ ] Cards use g100 background?

### 6. Ambient Brand Principle
- [ ] Can someone reading this asset figure out all three layers of the flywheel?
- [ ] Are we showing, not selling — the other layers are visible but not pushing?
