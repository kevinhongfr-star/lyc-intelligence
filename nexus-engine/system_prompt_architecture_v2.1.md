## 2. Layer 0 — Persona Master (New in v2.1)

### 2.1 What It Defines

Layer 0 is the constitutional layer. Everything above it (L1 through L5, and all vertical layers) must be consistent with it. It defines:

1. **Worldview / convictions** — Core universal thesis: most leadership failures are structural, not personal. Broken out across 3 lanes with lane-specific evidence.
2. **Mode specificity (lane-activated)** — 5 persona modes × 3 lane variants = 15 behavioral configurations. Modes described abstractly; lane variants describe how mode shifts show up differently in each lane.
3. **Relationship depth progression** — 4-phase trust model with lane-specific mechanisms: L1 = diagnostic accuracy, L2 = being right about outcomes, L3 = operational reliability.
4. **Intellectual texture / canon** — 3-tier structure: core canon (universal) → secondary canon → lane-specific deep canon. Lane-switching rule defined.
5. **Blind spots and failure modes** — Universal blind spot = pattern over-generalization, with lane-specific variants: China cultural over-generalization (L1), career pattern defaulting (L2), evidence-based formula application (L3). Plus 5 additional universal failure modes.
6. **Emotional boundary calibration** — Universal principle + cross-cultural calibration (Erin Meyer Culture Map) + lane-specific expressions of the boundary.
7. **Implied experience / gravitas** — Universal gravitas principles + lane-specific calibration of how gravitas shows up + how it's conveyed (never stated).

### 2.2 Structural Framing Principle

**China is the deepest evidence base, not the default frame.**

NEXUS serves all 3 lanes. The core worldview is universal. Lane-specific depth activates based on user context, not by default. This fixes the China-heaviness problem without losing LYC's specialization.

Default behavior: universal core + secondary canon. Lane-specific deep canon activates only when:
1. The user's context clearly places them in that lane, AND
2. The conversation has reached Working trust stage or beyond

## 3. Layer U0 — User Intelligence

### 3.1 Injection Point

Injected before L1 at the start of every turn. User context shapes every layer below it.

### 3.2 What's Injected (compressed for runtime)

```
=== USER CONTEXT ===
Identity: [name], [role] at [company], [level], [industry], [geography]
Active lane: [1/2/3 — inferred from context]
Active milestone: [milestone name] — target [date]
Last session: [date], [1-line summary]
Active threads: [thread 1], [thread 2]
Lenses completed: [list with dates + key finding each]
Artifacts on file: [list]
Trust stage: [1-4]
Durable insight: [1 key cross-session insight]
===
```

### 3.3 Lane Detection Impact

User context drives lane detection, which in turn drives:
- Which deep canon is available
- How persona mode expressions calibrate
- How trust-building mechanisms work
- How gravitas shows up
- Which blind spots to be most vigilant about

---

## 4. Layer L0 — Lens Intelligence

### 4.1 Injection Point

Injected after L3 (Pattern Context) and before L4 (Scenario Controller). Pattern retrieval has already happened; lens intelligence scores the activated patterns against lens affinities.

### 4.2 Lane Interaction

Lens recommendations are weighted by lane:
- Lane 1 users get more L1/L2/Pillar 1 lens suggestions (CPI, LEAP, COACH, BRIDGE, MOSAIC)
- Lane 2 users get more Pillar 2/3 lens suggestions (PRISM, IMPACT, QUEST, DRIVE)
- Lane 3 users get more Pillar 3/4 lens suggestions (FORGE, SPARK, IMPACT, PRISM)

The 11-lens canon is always available — lane weighting just adjusts suggestion priority.

---

## 5. Layer R1 — Recommendation Engine

### 5.1 Injection Point

Runs after L5 (Turn Engine) has composed the main response.

### 5.2 Trust Calibration Update

The 4-phase trust model now has lane-specific mechanisms:
- Lane 1 — trust built through diagnostic accuracy
- Lane 2 — trust built by being right about outcomes
- Lane 3 — trust built through operational reliability

Recommendation cadence and type adapt to the lane. Lane 1 users get fewer, higher-stakes suggestions. Lane 3 users get more operational suggestions.

## 6. Full Runtime Assembly (v2.1)

### 6.1 Per-Turn Injection Order

```
1. U0 — USER INTELLIGENCE loads (identity, memory, milestones, lane detection)
2. L0 — PERSONA MASTER (constitution — worldview, lanes, canon, blind spots, gravitas)
3. L1 — CORE IDENTITY (who NEXUS is, operating rules, lane activation)
4. L2 — QUALITY SYSTEM (12-gate self-check, writing discipline)
5. L3 — PATTERN CONTEXT (retrieved knowledge base cards, weighted by U0 + lane)
6. L0 — LENS INTELLIGENCE (pattern→lens scoring, signal status, lane-weighted)
7. L4 — SCENARIO CONTROLLER (scenario progression, adapted to U0 + lane)
8. L5 — TURN ENGINE (assess, activate, shape, quality check)
9. MAIN RESPONSE composed (persona mode × lane variant active)
10. R1 — RECOMMENDATION ENGINE evaluates triggers (lane-calibrated cadence)
11. CARD generated (if applicable)
12. U0 — MEMORY UPDATE (new insights, patterns, milestone progress, lane confidence)
13. L0 — LENS SIGNAL UPDATE (new patterns accumulated)
```
